# 🛡️ Ariadne Instructor Security Portal & Academic Integrity Gatekeeper

> **Live Interactive Demo:** [https://zydric.github.io/ariadne-instructor-portal/](https://zydric.github.io/ariadne-instructor-portal/)  
> **Course Pilot Context:** *CSIT 321 — Enterprise Web Systems & Security* (Cebu Institute of Technology – University)

---

## 🌟 Core Features

- **Automated Security Gradebook & Academic Integrity Audit:** Dynamic 0–100 scoring, Canvas/Moodle/CSV exports, and bypass detection (flagging commented-out vulnerabilities and suppressions).
- **Cohort Vulnerability Heatmap & AI Lecture Co-Pilot:** Real-time vulnerability density matrix across sections, trend analysis, talking points, secure code comparisons, and formative quizzes.
- **No-Code Assignment Guardrails:** Syllabus packs (2nd Year OOP, 3rd Year Web, 4th Year Capstone), zero-critical policies, and instant cohort re-scoring.
- **Ariadne CI/CD GitHub Bot Gatekeeper:** Spawns scanner checks against student PRs and generates realistic pedagogical review comments.
- **Universal In-Browser Demo Mode:** Runs standalone with rich mock data directly on GitHub Pages without requiring a backend.
